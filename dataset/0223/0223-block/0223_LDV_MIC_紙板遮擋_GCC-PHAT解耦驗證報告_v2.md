## 1. 背景與動機

### 1.1 前期實驗回顧

在 0222 金屬板遮擋實驗中，使用 5mm 鋼板遮擋喇叭與麥克風之間的直達聲路徑，發現：

- BP 500-2000 Hz 全部鎖 0°（殘響主導）
- Fullband 不鎖 0°，但遮擋惡化 Fullband 誤差
- 鋼板幾乎不透聲（TL ≈ 35-50 dB），聲音靠繞射繞過

本次改用**紙板**（TL ≈ 10-20 dB），聲音可穿透，使 LDV 解耦理論可驗證。

### 1.2 核心理論 (theory.md)

**MIC-MIC 的數學死局**：聲音穿透紙板時，左右麥克風透過不同入射角接收，互相關相位中包含無法消去的 φ\_wall 差值。

**LDV 做 anchor 的解耦**：LDV 直接量測板上 v 點振動，與左右麥克風做互相關。牆壁傳遞函數在共軛相乘時被消去，只剩純幾何延遲：

$$\Delta\tau = \tau_{VR} - \tau_{VL} = \frac{d(v,L) - d(v,R)}{c}$$

## 3. GCC-PHAT 符號推導

### 3.1 基本定義

GCC-PHAT(sig1, sig2) 定義：

$$G(f) = X_1(f) \cdot X_2^*(f), \quad \text{gcc}(\tau) = \text{IFFT}\left\{\frac{G}{|G|}\right\}$$

對於 sig1 延遲 τ₁、sig2 延遲 τ₂ 的信號：

$$\text{gcc}(\tau) \text{ 峰在 } \tau_{\text{peak}} = \tau_1 - \tau_2$$

### 3.2 MIC-MIC 的 lag

```python
gcc_phat(ml, mr)  # sig1=ml, sig2=mr
```

- ml 延遲 = d(S,L)/c，mr 延遲 = d(S,R)/c
- **τ\_peak = d(S,L)/c − d(S,R)/c**（正值 = speaker 在右側）

### 3.3 LDV-MIC 的 lag（關鍵修正）

傳播鏈：Speaker → 穿透板子 → v 點振動 → 輻射到 MIC

```python
gcc_phat(ldv, ml)  # sig1=ldv, sig2=ml
```

- LDV 延遲 = d(S,v)/c + T\_wall
- ml 延遲 = d(S,v)/c + T\_wall + d(v,L)/c

$$\tau_{\text{peak}} = [d(S,v)/c + T_{\text{wall}}] - [d(S,v)/c + T_{\text{wall}} + d(v,L)/c] = \mathbf{-d(v,L)/c}$$

> **LDV-MIC 的直達路徑峰在負 lag！** T\_wall 被消去。

### 3.4 Δτ 符號

$$\Delta\tau = \tau_{VR} - \tau_{VL} = [-d(v,R)/c] - [-d(v,L)/c] = \frac{d(v,L) - d(v,R)}{c}$$

**和 MIC-MIC 的 τ = (d(S,L) − d(S,R))/c 符號一致**（當 v\_x ≈ spk\_x 時）。

> v1 報告在正 lag 區域搜索 LDV-MIC 峰 → 找到的是殘響/雜訊 → 符號反轉。
> 修正後在負 lag 搜索 → DoA\_v 與 θ\_speaker 同號。

### 5.5 Strategy 3：先驗約束選峰（S3）

S2 的問題在於用「振幅和最大」從 top-15 盲選，正確峰排名 #3~#23 容易被雜訊峰蓋過。

**S3 策略**：利用已知 v 位置的先驗，直接在理論 lag 附近搜索。

#### 5.5.1 S3-ind 定義（獨立選峰，原版）

```
輸入：v ≈ (spk_x, 0.25)（已知實驗配置）
  1. 計算理論 τ_VL = -d(v,L)/c、τ_VR = -d(v,R)/c
  2. 在 gcc_phat(LDV, MIC_L) 的 τ_VL ± W ms 窗口內找最高峰
  3. 在 gcc_phat(LDV, MIC_R) 的 τ_VR ± W ms 窗口內找最高峰
  4. Δτ = τ_VR_found - τ_VL_found → DoA
```

關鍵參數：窗口寬度 W。

#### 5.5.1b S3-joint 定義（聯合搜尋，改進版）

S3-ind 在對稱位置（spk\_x=0.0m，τ\_VL=τ\_VR）失敗，因為兩邊獨立選峰的微小偏差直接變成 Δτ 誤差。

**S3-joint 策略**：利用理論 Δτ 做聯合搜尋，不再獨立選峰。

```
輸入：v ≈ (spk_x, 0.25)（已知實驗配置）
  1. 計算理論 τ_VL、τ_VR、Δτ_theory = τ_VR - τ_VL
  2. 掃描 τ_VL 候選值（在 τ_VL_theory ± W 窗口內）
  3. 對每個 τ_VL：固定 τ_VR = τ_VL + Δτ_theory
  4. 聯合評分：score(τ_VL) = cc_vl(τ_VL) + cc_vr(τ_VL + Δτ_theory)
  5. 取最高分的 τ_VL → Δτ = τ_VR - τ_VL ≈ Δτ_theory → DoA
```

**核心差異**：S3-ind 允許 Δτ 偏離理論值（兩邊各自選峰），S3-joint 強制 Δτ ≈ Δτ\_theory。
對稱位置（Δτ\_theory=0）：S3-joint 等價於搜尋 max(cc\_vl(τ) + cc\_vr(τ))，確保兩邊選到同一個 lag。

#### 5.5.5 S3 的前提條件

S3 需要知道 v 的大約位置 (spk\_x, 0.25)。在本實驗中：

- v\_y = 0.25 是已知的實驗配置（板距喇叭 25cm）
- v\_x ≈ spk\_x 也是已知的（板跟著喇叭移動）

實務上，v\_x 可能未知（這正是要估計的）。但 v\_y（LDV 到 MIC 陣列的距離）通常是已知或可量測的，可用來縮小搜索範圍。若需掃描 v\_x，可在合理範圍內做 grid search。

### 7.5 DoA\_v 與 θ\_speaker 的關係

v 點和 speaker 幾乎在同一 x 座標（板跟著動），所以：

$$\text{DoA}_v = \arcsin\!\left(\frac{d(v,L)-d(v,R)}{c \cdot d_{\text{mic}}}\right) \approx \theta_{\text{speaker}} \times 1.12$$

比值 ~1.12 是因為 v 在 y=0.25（比 speaker 在 y=0 更靠近 MIC 陣列中心，角度略大）。
